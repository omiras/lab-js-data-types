# JavaScript: cadenas de texto y números

Practica concatenación, métodos de cadenas, porcentajes y números aleatorios.

## Cómo trabajar

1. Descarga el ZIP y descomprímelo.
2. Abre la carpeta en Visual Studio Code.
3. Abre el HTML del ejercicio con **Open with Live Server**.
4. Lee «Antes de empezar» y «Tu turno».
5. Completa el JavaScript dentro de la etiqueta `<script>`, al final del HTML.
6. Guarda y abre **F12 → Consola** para consultar los resultados de `console.log()`.

Cada página contiene teoría, un ejemplo y un resultado esperado desplegable. El diseño se comparte mediante `style.css`. Recuerda utilizar el **prompt de clase** cuando necesites ayuda.
