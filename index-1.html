Ejercicio 1 · Trabalenguas

Une palabras y variables para construir una cadena de texto.

Antes de empezar

El operador + permite concatenar (unir) cadenas de texto. Puedes combinar variables y texto entre comillas.

const nombre = "Luna";
const saludo = "Hola, " + nombre + "!";
console.log(saludo); // Hola, Luna!

Los espacios también son texto. Añádelos entre comillas para que las palabras no queden pegadas.
