Ejercicio 3 · Calcular una propina

Utiliza operaciones aritméticas para calcular un porcentaje.

Antes de empezar

Para calcular un porcentaje, multiplica la cantidad por el porcentaje y divide entre 100. En JavaScript, * multiplica y / divide.

const precio = 60;
const descuento = precio * 10 / 100;
console.log(descuento); // 6

Los números se escriben sin comillas. JavaScript utiliza el punto como separador decimal: 2.5.
